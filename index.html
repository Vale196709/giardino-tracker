🔗 Sincronizza con Google Calendar
Serve un Client ID OAuth gratuito da Google Cloud Console (una volta sola):
  1. Vai su console.cloud.google.com → crea/scegli un progetto
  2. API e servizi → Libreria → abilita "Google Calendar API"
  3. API e servizi → Credenziali → Crea credenziali → ID client OAuth → tipo "App web"
  4. In "Origini JavaScript autorizzate" aggiungi l'indirizzo di questa app (es. https://vale196709.github.io)
  5. Copia il Client ID (finisce con .apps.googleusercontent.com) e incollalo qui sotto
Non connesso
Da questo momento, ogni scadenza con data creata/modificata verrà creata/aggiornata automaticamente anche su Google Calendar. La connessione va rifatta se scade il token (circa 1 ora) — riclicca "Connetti" quando serve.
